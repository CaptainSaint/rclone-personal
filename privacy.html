Privacy Policy

Rclone Personal is a personal application used to synchronise files between my local computer and my own Google Drive account.

Data Access

The application accesses Google Drive files only for personal file synchronisation.

Data Storage

OAuth credentials are stored locally by Rclone. Files are synchronised between my computer and my Google Drive account.

Data Sharing

The application does not sell or share Google user data with third parties.

Data Control

Access can be revoked at any time through Google Account security settings.
